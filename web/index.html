How to play

1. Click Join room, then allow camera access when asked.

2. Show your palm clearly in the frame.

3. Straighten a finger once, then bend it to play its note.

4. Use the same room code on both laptops.

Video uses peer-to-peer WebRTC where possible. Hand states travel through the room server; each browser synthesizes the same notes locally, so no microphone audio is transmitted.
